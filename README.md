# Vue 3 Pricing Component

A clean and modern pricing page component built with **Vue 3** (Composition API + `<script setup>`).

**Important:** This component contains **zero JavaScript logic** — only template markup and scoped CSS. No state, no reactivity beyond Vue's template, no API calls.

![Pricing Preview](screenshot.png)

## Features

- Three pricing plans: Starter (Free), Pro, Enterprise
- Highlighted "Best for" sections
- Feature lists with checkmark icons
- Responsive card layout using flexbox
- Comparison table at the bottom (easy to extend)
- Attractive accent color (#f59f0a)
- Fully static — no runtime logic or interactivity

## Technologies

- Vue 3 (Composition API + `<script setup>`)
- Vite (recommended development environment)
- Scoped CSS (plain CSS, no Tailwind, no external libraries)
