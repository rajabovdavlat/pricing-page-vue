# Vue 3 Pricing Component

A clean, modern **pricing page component** built with **Vue 3** (using `<script setup>` and Composition API).  
This is a **static-first** component — it contains **no JavaScript logic**, state management, interactivity or API calls. Everything is done with **HTML structure + scoped CSS**.

Perfect as a starting point for:
- SaaS / B2B landing pages
- Subscription / membership pages
- Dashboard upgrade screens
- Marketing websites

## Features

- Three pricing plans: Starter (Free), Pro, Enterprise
- Highlighted "Best for" section
- Feature lists with checkmarks
- Responsive card layout (flexbox)
- Attractive orange accent color (#f59f0a)
- Comparison table at the bottom (partially filled — easy to extend)
- Pure Vue 3 + scoped CSS (no external UI libraries)
- **Zero runtime JavaScript logic** — just declarative template + styles

## Technologies

- Vue 3 (Composition API + `<script setup>`)
- Vite (recommended dev environment)
- Scoped CSS (no Tailwind, no CSS-in-JS, just plain CSS)

## Installation & Usage

```bash
# 1. Clone or download the repository
git clone https://github.com/your-username/vue-pricing-component.git
cd vue-pricing-component

# 2. Install dependencies (if you use Vite project)
npm install

# 3. Start development server
npm run dev

# Open http://localhost:5173 (or the port Vite shows)
