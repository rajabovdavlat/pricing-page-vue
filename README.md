# Vue 3 Pricing Component

Компонент страницы ценообразования (тарифы) на Vue 3 + <script setup>.

## Технологии
- Vue 3 (Composition API)
- Vite (если используется)
- CSS (scoped)

## Установка и запуск

```bash
npm install
npm run dev

### Compile and Minify for Production

```sh
npm run build
```
